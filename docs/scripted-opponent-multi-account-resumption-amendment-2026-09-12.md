# Scripted-opponent multi-account resumption amendment, 2026-09-12

This amendment is written before any new model-output request. It reopens the
unfinished two-route completion only as a new, explicitly labelled collection
contract. The earlier plan and all of its failure records remain immutable.

## What this amendment addresses

The 2026-09-11 completion plan stopped after one valid Claude Opus 5 cell and
multiple HTTP 403 quota refusals. A later GPT-5.5 attempt also received an
explicit 403 after a successful minimal smoke test. The smoke test established
reachability, not capacity for a structured game cell. The five authorised
benchmark profiles were then refreshed with their own `benchmark.env` files;
refreshing credentials is an infrastructure repair, not evidence that quota is
available.

The purpose of this amendment is to make one bounded, auditable resumption
attempt using all five named collaborator identities, with a workload-matched
probe before any full cell. It is not permission to rotate a refused cell until
one account happens to pass.

## Frozen contract

The game, prompt bytes, parser, four scripted strategies, three risk levels, ten
races per cell, seat counterbalance, random streams, protocol ID and stopping
rule are unchanged. The already committed task source remains the source of
truth. The resumption contract is:

| Field | Frozen value |
|---|---|
| Protocol | `ai-race-scripted-opponent-v1` |
| Model routes | `claude-opus-5-default`, `gpt-5.5-2026-04-23` |
| Output cap | `1024` tokens, OpenAI-compatible `max_tokens` |
| Reasoning | `low` for both routes |
| Unit | one complete `(strategy, risk)` cell per task version |
| Cell size | 10 races, 93 route decisions expected |
| Source | canonical task with only the two axis selectors baked to one cell |

This is a distinct decoding contract from the earlier 256- and 512-token
attempts. It is also not silently pooled with the three complete routes whose
earlier manifests used a different contract. Any successful new route is
reported as a separately identified resumption result until a contract-aware
comparison is written.

## Account assignment and stopping

Only these five authorised profiles may be used: `foundnotkiet`, `kit567`,
`hunhtrungkit`, `tnkiet` and `trungkiet`. The assignment is fixed before the
first full-cell run. Cells are assigned by deterministic round-robin over the
ordered identities, with GPT-5.5 starting at offset 0 and Claude Opus 5 at
offset 1. The existing Opus `AS` at risk `0.6` cell is not recollected.

The order is risk `0.6`, then `0.9`, then `0.1`; within each risk Claude Opus 5
comes before GPT-5.5. The first probe for each route/profile is a diagnostic
only and is stored outside the campaign evidence tree. A full cell is attempted
only on the profile assigned to that cell.

- A 403 quota refusal retires that profile for this amendment. Its remaining
  assigned cells stay not collected; no cell moves to another profile.
- A 429 heavy-load or timeout failure may be retried on the same assigned
  profile at most twice, with the frozen source and deterministic backoff.
- A successful run is ingested only after the existing fail-closed cell audit.
- A validation run caused by `task push` is overhead and is never downloaded as
  a second campaign cell.

The amendment therefore tries every currently authorised route/profile pairing
that survives the workload probe, while preserving a fixed estimand and a
truthful missing-cell record if quota remains unavailable.

## Provenance requirements

Each task source is generated by `scripts/bake_scripted_opponent_cell.py` from
the canonical committed source. The staged file is outside the repository. For
each attempt, record task version, profile, route, cell, source hashes, command
outcome, HTTP class, and whether any race completed. Credentials and API keys
must never enter logs, manifests, commits, or paper files.

No manuscript claim changes during this amendment. Only a complete route with
all twelve cells may upgrade the headline from three admitted endpoints; a
partial route remains an explicitly incomplete diagnostic result.
