# Activation-level sparse autoencoder pilot

## Current evidence hierarchy

The original cross-runtime attribution runs documented below remain useful
association baselines. Two newer native-runtime audits supersede them for causal
claims:

- [`causal_selfplay/fast-sae-pilot-L12-v1/analysis`](causal_selfplay/fast-sae-pilot-L12-v1/analysis/):
  actual constrained-policy self-play with whole-race discovery/evaluation,
  fixed-state dose/sign/reconstruction/matched-random/unrelated-feature controls,
  and 114 live common-random-number reruns. Held-out association survived, but
  0/12 strongest-dose target-minus-control intervals excluded zero.
- [`context_fast_sae_analysis`](context_fast_sae_analysis/): layer-12/layer-20
  context screen. Layer 20 reached held-out AUC .985, but neither layer caused an
  action flip across 1,312 interventions per layer; it is promoted for diagnostic
  capture only, not steering.

No artifact in this directory establishes a monosemantic Unsafe feature or a
feature-specific causal strategy controller.

This directory contains the first completed neuron-level XAI pilot for AI Race
decisions. It replays frozen Qwen2.5-7B-Instruct surface-sensitivity prompts
through the native Hugging Face checkpoint, captures residual-stream activations,
and encodes them with pinned pretrained FAST JumpReLU SAEs. It is separate from
the logged-feature dictionary surrogate under `prompt_sensitivity_pilot/`.

## Admitted result sets

| Capture position | Decisions | Train / eval | Layers | Exact-prefix crossing | Mean eval AUC | Mean shuffled AUC |
|---|---:|---:|---|---:|---:|---:|
| Before action label, after common `ACTION:` prefix | 600 | 480 / 120 | 4, 12, 18, 20, 25 | 0 | 0.872 | 0.496 |
| Prompt last token, before response boilerplate | 600 | 480 / 120 | 4, 12, 18, 20, 25 | 0 | 0.842 | 0.492 |

Both positions use the same sampled decisions, seed, 4,096-feature train-only
variance screen, ridge/LSQR linear probe, and 20 label shuffles per layer. The
split groups the transitive connected components induced by whole-race membership
and identical causal-prefix hashes. No race or exact prefix crosses train/eval.
No prompt exceeded the 2,048-token SAE context and no probe/control fit reported a
convergence warning.

## Main descriptive findings

- Held-out ROC-AUC is 0.849–0.886 after the common `ACTION:` prefix and
  0.807–0.865 at the stricter prompt-last position.
- Removing the response boilerplate lowers mean AUC by 0.030, but action
  information remains above the shuffled-label baselines at every audited layer.
- Reconstruction normalized MSE is low (2.35e-5 to 8.71e-4 pre-action), but the
  decision-position codes are unexpectedly dense: mean L0 is 13,273–17,958 of
  28,672 features (46%–63%). This is an interpretability warning, not a success
  metric.
- For the displayed top eight overlapping train-selected features per layer,
  all 40 retain their association sign on held-out data. This is a descriptive,
  selection-conditioned check; it is not an FDR-corrected feature discovery result.

## Evidence boundary

The logged decisions were generated by Ollama GGUF F16 digest
`59805ce4a4046be2d8f63231a78daacd2e66f5dccf1a64d0d138ebeeb26ff16c`,
whereas attribution uses Hugging Face revision
`a09a35458c702b33eeacc393d103063234e8bc28`. Manifests therefore label every run
`cross-model exploratory association only`. The results show that SAFE/UNSAFE
labels are linearly recoverable from a near-lossless sparse-code representation;
they do not identify the model's unique reason, prove monosemantic features, or
establish a causal mechanism. The dense L0 and runtime mismatch make steering,
same-runtime greedy generation, random-direction controls, and downstream
KL/loss-recovery gates mandatory before causal language.

## Where to look

- `figures/sae_token_position_robustness.{png,pdf}`: primary position comparison.
- `surface_n600_strict_pre_action/figures/`: fidelity, probe/control, and
  train-versus-eval feature figures for the primary position.
- `surface_n600_strict_prompt_last/figures/`: the same views before any response
  boilerplate.
- Each lane directory contains its immutable `manifest.json`, sample audit,
  top-code rows, reconstruction metrics, probe metrics, negative controls, and
  feature associations. The two lane manifests are merged only after sample IDs,
  labels, splits, capture hashes, model revision, SAE revision, and provenance
  match exactly.

Reproduce and audit with:

```bash
python results/scripts/run_activation_sae.py --help
python results/scripts/visualize_activation_sae.py --help
python results/scripts/compare_activation_sae_positions.py --help
```
