# GreenNode exogenous position-endowment diagnostic

This directory is the complete local clone of the two-lane GreenNode run for
`ai-race-position-endowment-v1`, plus a reproducible local analysis. It is a
**completed, unadmitted behavioral diagnostic**, not evidence that either model
understood or optimized the game.

## Frozen run

- Source commit: `e3cf82523bd2a342f9cfb62db2fd445682390756`
- Block 1: 192/192 responses, 0 parse failures
- Block 2, models swapped across GPU lanes: 192/192 responses, 0 parse failures
- Prompt bank: 96 states per checkpoint; N=2 and N=3; both opaque
  action mappings; numeric-only and verified-rank-label arms
- Decoding: greedy temperature 0, BF16, CUDA-only
- Checkpoints: pinned Qwen2.5-7B-Instruct and Mistral-7B-Instruct-v0.1
  revisions; bundled admission receipts bind model metadata digests
- Block 1 is primary. Block 2 is a technical lane replication and is never
  pooled as an independent behavioral sample.

The primary numeric-only N=3 contrast for Qwen was **last minus leader =
+41.7 percentage points**. The matched probe action agreement across swapped
GPU lanes was **94.8% for Qwen** and **100% for Mistral**. Mistral emitted Safe
for every position prompt in both blocks, so its position contrasts are zero.
These are exact rates over one frozen state bank, without model-sampling
confidence intervals.

## Admission and protocol boundary

Both checkpoints failed the separate 2-player comprehension gate. Aggregated
over its admission grid, Qwen reached 2.5% state-update and 0% terminal-scoring
accuracy; Mistral reached 0% and 2.5%, respectively. That gate also does not
admit N=3 comprehension. Therefore the result supports only a direct response
to an engine-scored, payoff-relevant position prompt under this checkpoint and
template.

The coordinator's experiment requests use `ai-race-position-endowment-v1`.
The shared inference worker returns the generic
`ai-race-heterogeneous-dyad-v1` mailbox envelope. The original coordinator did
not validate that envelope protocol or its returned request ID. The retained
post-run analyzer now fails closed on both fields and additionally verifies the
raw request/response hashes, routes, order, seeds, model digests, frozen prompt
bank, and response coding. The future runner is also hardened to validate these
fields online.
