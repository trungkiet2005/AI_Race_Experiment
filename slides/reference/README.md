# Deck design reference

`refs.tex` is a Beamer deck from an unrelated project (Loss-of-Plasticity), kept
as a **structural** template: how it sequences a research talk, and its
`hl`/`tc`/`bad`/`good` semantic macros. It is not a bibliography and nothing in
this repository compiles it. Its colours and topic are deliberately not followed;
`ai_race_research_deck.tex` uses the RaceInk palette instead.

[`../progress/plan.md`](../progress/plan.md) records exactly which parts were
borrowed and which were rejected, including why its hard-coded TeX Live font
paths were dropped in favour of a self-contained sans stack.
