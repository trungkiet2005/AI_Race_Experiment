04 / GAME UNDERSTANDING AUDIT

Knowing the table
is not knowing the game.

One Qwen2.5 7B F16 checkpoint was tested with 41 atomic questions, five fixed-seed repetitions, paraphrases, answer-order reversals and verified calculator outputs. This is pilot evidence, not a claim about every model.

PROBE OUTPUTS685 / 685all raw prompts + responses retained
UNAIDED ACCURACY52.1%semantic scoring, strict format separate
CALCULATOR ACCURACY75.6%disclosed-answer tool uptake
BEHAVIOR PARSE FAILURES01,116 logged decisions
WHAT PASSED

Exact engine oracle, browser parity, source/model hashes, paired hidden horizons, prompt reconstruction and calculator re-computation.

WHAT IT SUPPORTS

Rule and arithmetic performance under this checkpoint, prompt pool, decoding contract and mechanism.

WHAT IT DOES NOT SUPPORT

An internal world model, subjective understanding, stable risk preference or generalization to other models.
