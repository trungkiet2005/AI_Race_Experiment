# Source-study assets

These files are inputs reproduced from the human AI-race source study, not
outputs of this repository. They were moved out of the former visualization
archive so `results/` contains only canonical project evidence and does not
duplicate publication, slide, or analysis artifacts.

  source-study paper snapshot.
- `FIG-1.pdf`--`FIG-3.pdf` and `FIG-S1.pdf`--`FIG-S4.png`: source-study figure
  snapshots retained for traceability.
